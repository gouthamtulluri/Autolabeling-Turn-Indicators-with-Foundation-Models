# Autolabeling Turn Indicators with Foundation Models

**Automated and Connected Driving Challenges - Research Project (09/2026)**  
*Research Topic 17*

Accurately detecting turn indicator states is vital for autonomous driving systems to anticipate the intent of surrounding vehicles. This repository contains an automated multi-stage pipeline that extracts, associates, and labels turn indicator states (Left/Right, ON/OFF) using cutting-edge foundation models without the need for task-specific training.

Our pipeline leverages the **DrivIng dataset**, combining surround-view RGB cameras and LiDAR, to robustly estimate indicator states across diverse lighting conditions (Day/Night) using the Segment Anything Model 3.1 (SAM 3.1) and Depth Anything 3 (DA3).

## ✨ Key Features

1.  **Dense Depth Fusion**: Fuses sparse LiDAR point clouds with relative depth maps generated by **Depth Anything 3 (DA3)** to create dense metric depth maps.
2.  **Zero-Shot Segmentation**: Utilizes **Segment Anything Model (SAM 3.1)** to isolate vehicle indicator clusters using simple text prompts (e.g., "car taillight").
3.  **3D Geometric Association**: Maps 2D segmentation masks to 3D vehicle track IDs using 2D/3D bounding boxes and depth heuristics.
4.  **Robust Photometric & Frequency Filtering**: 
    *   Extracts true amber pixels using a calibrated **CIELAB ($L^*a^*b^*$) color space** filter to resist overexposure and brake light bleed.
    *   Employs a frequency-based rhythm analysis (rolling median detrending + autocorrelation) to correctly identify the 1-2Hz blinking patterns defined by ECE standards.
5.  **Multi-Camera Fusion**: Fuses observations across 6 overlapping RGB cameras into a unified global state coordinate frame.

## 🛠 Prerequisites & Setup

### Hardware Requirements
*   **GPU**: Minimum 10 GB of VRAM is required to load DA3-Giant and SAM 3.1 models in half-precision (CUDA required).

### System Dependencies
Python 3.10 is required for compatibility with the latest Hugging Face architectures.

```bash
# 1. Install system dependencies (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y ros-noetic-sensor-msgs libgl1

# 2. Create Conda Environment
conda create -n sam_env python=3.10 -y
conda activate sam_env

# 3. Install Dependencies
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu124
pip install git+https://github.com/ByteDance-Seed/depth-anything-3.git@3d835ec1a5802d64a8b8b15f817a1ab54809bfe4
pip install ipykernel
python -m ipykernel install --user --name sam_env --display-name "Python 3.10 (SAM 3.1)"
```

### Hugging Face Authentication
The pipeline relies on large foundation models restricted by licenses. You must authenticate to download the weights:
1. Accept the Meta license for SAM 3.1 on Hugging Face.
2. Generate a Read token in your Hugging Face settings.
3. Export the token in your environment or set it in the script:
   ```python
   import os
   os.environ["HF_TOKEN"] = "YOUR_HF_TOKEN"
   ```

## 🚀 Usage

The full execution logic is detailed in `report.ipynb`. 

### 1. Run the Main Pipeline
The master orchestrator function `process_all_valid_images_with_sam` iterates through all valid vehicle timestamps, generates masks, fuses LiDAR, and associates detected indicators.

```python
# Assuming configurations and models are loaded (see notebook)
df_final_results = process_all_valid_images_with_sam(
    camera_dataframes=camera_dataframes,
    sync_table=sync_table,
    calib_data=calib_data,
    data_root="data/data_night_sample",
    processor=sam_processor,
    model=sam_model,
    device="cuda",
    depth_model=da3_model,
    save_csv=True
)
```

### 2. Run Blink State Estimation
After extracting amber percentages, pass the dataframe through the temporal frequency filter to tag `BLINKING` or `OFF` states:

```python
df_camera = detect_blinks_per_camera(df_final_results, fps=10.0)
```

### 3. Fuse to Global Track
Resolve multi-camera overlaps and finalize the indicators into a unified coordinate frame:

```python
df_global = fuse_to_global(df_camera)
```

Outputs will be saved in the `runs/` directory (e.g., `SAM3_hybrid_final_<dataset_name>.csv`).

## 📊 Evaluation & Experiments

The repository includes tools for deep-dive ablation studies (located in `functions/experiments.py`):
*   **SAM3 Parameter Tuning:** Sweep `conf_threshold` and `mask_threshold`.
*   **Depth Map Fusion Verification:** Compare DA3 raw relative outputs versus localized LiDAR scaling.
*   **CIELAB Amber Sweeps:** Adjust $r_{max}$ and $b_{min}$ thresholds to observe performance shifts between Day and Night overexposure scenarios.
*   **Blink Rhythm Tuning:** Evaluate autocorrelation peak limits and median detrending windows against ground truth samples.
